# Tyga Developer Documentation

This `doc/` folder contains practical, project-specific documentation for developers working in this repository.

Use these docs to:
- understand the current folder layout and where code lives
- add a new page or route in the Next.js App Router
- create or extend components and UI primitives
- understand how portals and overlay components are organized
- review suggested workspace improvements for the repository

## What is in this folder?

- `folder-structure.md` — explains the repository’s main directories and responsibilities
- `page-routing.md` — describes how the Next.js App Router is currently used and how to add new pages and route groups
- `component-guidelines.md` — explains how to organize and build reusable components, including `components/ui` and `components/portals`
- `portals.md` — describes the portal pattern and how overlay components are implemented here
- `improvements.md` — detailed suggestions for workspace and structure improvements

## Note

There is also an existing `docs/` folder in this repository used for contributor and process documentation. `doc/` is intentionally focused on codebase architecture, onboarding, and technical developer guidance.
