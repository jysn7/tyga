# TYGA documentation

This folder contains the project's maintained documentation. Feature behavior is documented separately from development guidance and contribution conventions.

## Start here

- [Feature documentation](./features/README.md) — current product capabilities, route and hook coverage, and known implementation boundaries.
- [Development guides](./development/README.md) — authentication, routing, repository structure, components, and overlay portals.
- [Project and contribution guides](./project/README.md) — contribution workflow and naming conventions.

## Documentation principles

- Treat source code, Supabase migrations, and tests as the final authority when documentation and implementation differ.
- Distinguish shipped UI from database or API capabilities that do not yet have a user-facing workflow.
- Keep one canonical guide for each topic and link to it instead of copying large sections between documents.
