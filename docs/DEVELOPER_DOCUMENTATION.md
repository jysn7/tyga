# Developer Documentation Index

Developer-facing documentation for this repository is stored in the root `doc/` folder.

The folder contains:

- `doc/README.md` — overview of the developer docs and file purpose
- `doc/folder-structure.md` — current repository structure and folder responsibilities
- `doc/page-routing.md` — how the Next.js App Router routes are organized and how to add new pages
- `doc/component-guidelines.md` — component organization, naming, and styling guidance
- `doc/portals.md` — how overlay components and portal wrappers are implemented
- `doc/improvements.md` — suggested workspace improvements for future reorganization

If you do not see the `doc/` folder in your editor, refresh the file explorer or reopen the workspace.
